## 一、项目介绍

VocaTa（语Ta）是一个 AI 驱动的角色扮演平台——用户可与 Harry Potter、Socrates 等虚拟角色进行**语音和文本对话**。

核心特性：

- **实时对话**：文本聊天走 WebSocket 流式响应；语音走 STT → LLM → TTS 全链路。
- **多 LLM 集成**：七牛云、OpenAI、Google Gemini、SiliconFlow 等 provider 可切换。
- **自定义角色**：用户可创建 AI 角色，配置性格、对话风格、音色，并支持 AI 辅助生成角色设定。
- **角色发现**：角色标签、分类、热度（聊天次数）、收藏。
- **前后端分离 + 容器化 + CI/CD**：单体 Spring Boot 后端按模块分包，Vue 3 前端分用户端/管理端。

## 二、当前已实现的功能模块

以下为代码中**真实存在**的能力（演示视频等早期素材仅供参考）：

### 2.1 用户与认证（auth / user）
- 邮箱验证码注册（6 位验证码，有效期 5 分钟），新用户自动生成用户名。
- 邮箱 + 密码登录、登出、忘记密码重置；基于 Sa-Token 的会话与权限。
- 个人资料查看/编辑、头像上传（七牛云 CDN）、收藏角色（`UserFavorite`）。

### 2.2 角色（character）
- 角色 CRUD、标签管理、按标签筛选、热度（聊天次数）统计。
- AI 辅助生成角色设定。

### 2.3 对话（conversation）
- 文本对话，WebSocket 流式逐字返回，多轮上下文保持。
- 会话与消息存储、历史记录、自动生成会话标题、软删除。

### 2.4 语音与 AI（ai / voice）
- 语音链路 **STT → LLM → TTS**（WebSocket 实时交互、音频流、心跳保活）。
- LLM provider 抽象，多家可切换；STT：七牛云 / 科大讯飞；TTS：火山 / 科大讯飞。
- TTS 音色管理与音色配置（voice 模块）。

### 2.5 文件（file）
- 七牛云文件上传（头像、图片等），CDN 加速访问。

### 2.6 管理端（admin）
- 管理员登录鉴权、用户管理、TTS 音色管理。

## 三、技术架构（高层）

**后端**：Java 17 + Spring Boot 3.1.4，**单体应用按业务模块分包**（非微服务）。MyBatis Plus + PostgreSQL + Redis(Lettuce/Redisson)，Sa-Token 鉴权，WebFlux `WebClient` 调第三方 AI，Spring WebSocket 承载流式聊天。

**前端**：Vue 3 + TypeScript + Vite。用户端 `vocata-web` 用 SCSS；管理端 `vocata-admin` 用 Tailwind CSS 4。Element Plus + Pinia + Vue Router + Axios。

**真实模块（10 个）**：`auth` `user` `character` `conversation` `ai` `voice` `file` `admin` `common` `config`。

> 依赖版本以各 `pom.xml` / `package.json` 为准，本文不写死小版本号（避免漂移）。完整技术栈与版本见 `README.md` 与 `.ai-rules/tech.md`。

### 架构设计原则
1. **前后端分离**：前端独立部署，经 RESTful API + WebSocket 与后端通信。
2. **模块化单体**：按业务领域分包（非微服务），统一构建部署。
3. **AI 抽象层**：`LlmProvider` / `SttClient` / `TtsClient` 接口屏蔽厂商差异，支持切换。
4. **安全为先**：Sa-Token 鉴权 + 路由分级（`/api/open|client|admin`）+ 参数校验。

### 关键流程
- **认证**：登录 → Sa-Token 校验 → 会话写 Redis → 返回 Token；后续请求经 Token 校验构建 `UserContext`。
- **AI 对话**：语音输入 → STT → LLM → TTS → 语音输出；文本输入 → LLM 流式 → 消息存储 → 前端渲染。provider 默认 `qiniu/qiniu/xunfei`，可在配置切换。
